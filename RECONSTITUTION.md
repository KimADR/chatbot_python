# Note de reconstitution

Cette archive a ete reconstituee le 19 octobre 2026 a partir de la discussion HTML sauvegardee « Mise en page TekFutura » et de la capture Orinasa embarquee dans cette discussion.

Le fichier HTML conservait le nom `chatbot_python-main.zip`, les fonctionnalites annoncees, les documents mentionnes et la capture d'ecran, mais **pas les octets de l'archive ZIP originale ni l'historique Git du depot source**.

Cette livraison reproduit donc le plus fidelement possible le perimetre explicitement decrit : FastAPI, SQLite local, tableau de bord, equipements, incidents, historique, assistant par recherche locale, 14 fiches, calculs, export CSV, tests, Docker, GitHub Actions, scripts de lancement, sauvegarde et documentation.

Elle ne doit pas etre presentee comme une copie binaire de l'archive precedente. Pour recuperer exactement le depot Git d'origine ou ses commits, il faut disposer du ZIP source ou reconnecter le depot GitHub d'origine.
