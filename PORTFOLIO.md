# Orinasa — fiche portfolio

## Probleme traite

Dans un petit atelier ou une unite de production, les informations sur les incidents peuvent etre dispersees entre cahiers, messages et memoire des equipes. Orinasa propose une interface simple pour consigner les faits essentiels, suivre leur statut et retrouver des fiches de reference.

## Proposition de valeur

**Observer. Consigner. Transmettre.**

Le prototype permet de montrer comment une application legere peut structurer le suivi d'incidents sans imposer une infrastructure lourde ni un abonnement a une API d'IA.

## Fonctionnalites demonstrables

- tableau de bord operationnel ;
- gestion d'equipements ;
- declaration et suivi d'incidents ;
- historique des changements ;
- estimation des temps et couts d'arret ;
- 14 fiches atelier ;
- assistant de recherche locale ;
- export CSV ;
- calculs TRS et conversions ;
- interface responsive.

## Technologies

Python, FastAPI, SQLite, HTML, CSS, JavaScript, pytest, GitHub Actions et Docker.

## Scenario de demonstration en 3 minutes

1. Ouvrir le tableau de bord et montrer les indicateurs.
2. Declarer un arret sur un equipement avec une duree et une priorite.
3. Passer l'incident `En cours` puis `Resolu`.
4. Poser une question dans l'assistant pour retrouver une fiche locale.
5. Montrer le calcul de cout : 45 minutes a 80 000 Ar/h = 60 000 Ar.
6. Exporter la liste en CSV.

## Competences mises en evidence

- conception d'une API web ;
- modelisation SQLite ;
- validation de donnees ;
- conception d'interface responsive ;
- tests automatises ;
- documentation et packaging ;
- traduction d'un besoin metier en prototype demonstrable.
